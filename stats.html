⚙️ Google Apps Script Webhook Csatlakozás
Demó adatok
ℹ️ Jelenleg mintaadatok láthatóak. Illeszd be a Google Apps Script Web App URL-t a valós adatok betöltéséhez!
▶ Hogyan kell beállítani a Google Apps Script végpontot az adatok lekéréséhez? (Kattints ide)

1. lépés: Nyisd meg a Google Táblázatod Apps Script szerkesztőjét.

2. lépés: Győződj meg róla, hogy a doGet(e) függvény kezeli a ?action=getEvents kérést. Példa kód:

function doGet(e) { if (e && e.parameter && e.parameter.action === "getEvents") { // Táblázat eseményeinek visszaadása JSON formátumban const ss = SpreadsheetApp.getActiveSpreadsheet(); const sheet = ss.getSheetByName("Events") || ss.getActiveSheet(); const rows = sheet.getDataRange().getValues(); // Vagy ha összesített számokat tárolsz: return ContentService .createTextOutput(JSON.stringify({ status: "success", events: getEventCountsFromSheet(sheet) })) .setMimeType(ContentService.MimeType.JSON); } return ContentService.createTextOutput(JSON.stringify({ status: "ok" })) .setMimeType(ContentService.MimeType.JSON); }

3. lépés: Kattints a Telepítés ➔ Új telepítés (New deployment) pontra (vagy Telepítések kezelése ➔ Új verzió), hozzáférés: Bárki (Anyone).
